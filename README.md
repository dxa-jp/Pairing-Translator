# ペアリング翻訳

近くのAndroid端末同士を接続し、Sonioxで音声認識・翻訳を行うアプリです。
端末間通信にはGoogle Play ServicesのNearby Connectionsを使用します。

アプリID（v0.2.5以降）: `com.navypool.pairingtranslator`

v0.2.4以前とは別アプリとしてインストールされます。設定・端末登録は自動移行されないため、初回起動時に権限、入力言語、サーバーでの端末承認を設定してください。動作確認時は旧版を終了しておきます。

## ビルド

- Android Studio、JDK 17以上、Android SDK 36
- Android 8.0（API 26）以上のGoogle Play Services搭載端末
- `local.properties` に各環境の `sdk.dir` を設定

```powershell
.\gradlew.bat :app:assembleDebug
```

生成先: `app/build/outputs/apk/debug/app-debug.apk`

## サーバーとモデル設定

既存のMultiTranslatorバックエンドを利用します。端末登録後、管理画面での承認が必要です。
v0.2.2以降は、一時キーAPIの `model` をSoniox接続に使用します。
モデル名をアプリに固定せず、接続開始・再接続・セッション更新時に取得します。
モデル名が未取得・不正な場合はエラーとして停止します。

## 言語混在の修正（v0.2.4）

- 両端末の言語をヒントとして識別させ、厳格な言語強制は無効にします。
- 対象外の言語と翻訳対象外のトークンを除外します。
- 日本語ラベルが付いても、日本語文字を含まない原文は途中表示・送信しません。日本語文中の英字は維持します。
- 途中結果は置き換え表示し、発話終端で確定原文・訳文を一度だけ送信します。
- 日本語端末・英語端末の両方を更新してください。

実Sonioxへ日英の合成音声を送り、日→英・英→日の両方向で対象外音声が `none` になることを確認しています。その応答を使う回帰テストも含めています。
v0.2.4のDebug APKビルド・署名検証と16件のテストが成功しています。
日本語端末CP08_J1へv0.2.4を適用し、ユーザー発話の英語2文が除外され、日本語2文だけが自分の吹き出しに表示されることをADBログ・画面で確認済みです。相手端末P30Aの更新後の確認は未実施です。
日本語設定では英字・数字だけの発話（「USB」など）も除外されます。日本語へ音写される誤認識や、話者の識別まで保証するものではありません。
Android Lintでは既存の `InvalidFragmentVersionForActivityResult` エラーが残っています。
