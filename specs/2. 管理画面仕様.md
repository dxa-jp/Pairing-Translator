# ペアリング翻訳 管理画面仕様

> 本プロジェクト(ペアリング翻訳)は **クライアント専用** であり、独自の管理画面・サーバーを持たない。
> 管理は姉妹プロジェクト **MT (D:\MultiTranslator)** のサーバー/管理画面を利用する(読み取り専用の関係)。

## 1. 利用するバックエンド

| 項目 | 値 |
|---|---|
| サーバー | `https://multitranslator.dev.x-tools.biz/`(設定画面で変更可能、初期値) |
| 端末登録 | `POST /api/device_auth.php`(device_id を送信、管理UIでの承認が必要) |
| 一時キー発行 | `POST /api/temp_key.php`(device_id + duration 1〜60分) |

### レスポンス概要

- `device_auth`: `success` + `data.status`(true=承認済み)。未承認なら `未承認(管理UIで承認してください)` を診断/ログに表示
- `temp_key`: 成功時 `temp_api_key` + `model`(例 `stt-rt-v5`) + `expires_in_seconds` + `expires_at`。失敗時 `error_code` / `message`
- エラーコード: `DEVICE_NOT_APPROVED`(端末未承認) / `QUOTA_EXCEEDED`(月次使用上限) — **再試行しない**(Rejected として扱いユーザーに表示)
- ネットワーク系エラー(Error)は VoiceSessionManager のバックオフ再接続で自動復旧

## 2. 管理画面(MT側)で行う運用

| 操作 | 説明 |
|---|---|
| 端末承認 | ペアリング翻訳を起動した端末の device_id(UUID) を MT 管理UIで承認する。未承認でもアプリは動くが Soniox キー取得が拒否され翻訳不可 |
| 使用量管理 | 月次クォータ消費は Soniox の音声トークン。管理UIのグラフで確認。**音声は送信した時間で課金**(無音・対象外言語も含む。VAD なし常時送信) |
| サーバー設定 | DNS は IPv4-only(OCI が IPv6 inbound を遮断)。詳細は親リポジトリ `D:\HonyakuSapo\specs\7.` |

## 3. ペアリング翻訳側の制約メモ

- 管理画面・API の変更は **MT 側で行い、本プロジェクトは追従するだけ**(契約のキャノンは親 `D:\HonyakuSapo\specs\4. API仕様.md`)
- `BackendClient.baseUrl` は設定画面から上書き可能(テストサーバー切替用)。デフォルトへ戻すボタンあり
- デバイスID は初回起動時に UUID を生成して `poc_prefs.device_id` に永続化。管理画面承認にその値を貼り付ける(設定の「コピー」ボタン)
